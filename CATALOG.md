## Icon Specifications

All icons in this repository follow these specifications:

- **Format:** SVG (Scalable Vector Graphics)
- **Size:** 24x24 viewBox
- **Stroke Width:** 2px
- **Style:** Outline/stroke-based
- **Color:** Uses `currentColor` for easy theming
- **Accessibility:** Semantic naming for screen readers
