# Icons Repository

A collection of publicly available SVG icons for use with Cloudflare Access applications and other projects.

## 🎯 Purpose

This repository hosts clean, simple SVG icons that can be easily referenced and used in Cloudflare Access applications. All icons are optimized for web use and are publicly accessible.

## 📂 Available Icons

The following icons are currently available in the `icons/` directory:

- **book.svg** - Documentation or reading material
- **clock.svg** - Time-related applications
- **cloud.svg** - Cloud services
- **code.svg** - Development tools
- **dashboard.svg** - Admin panels and dashboards
- **database.svg** - Database applications
- **file.svg** - File management
- **folder.svg** - Directory or project organization
- **home.svg** - Homepage or main portal
- **info.svg** - Information or help
- **link.svg** - URL shorteners or link management
- **lock.svg** - Security or access control
- **mail.svg** - Email services
- **package.svg** - Package management

- **settings.svg** - Configuration pages
- **shield.svg** - Security services
- **user.svg** - User profiles
- **users.svg** - Team or multi-user applications

## 🚀 Usage

### Using with GitHub Raw URLs

You can reference these icons directly using GitHub's raw content URLs:

```
https://raw.githubusercontent.com/TheNetworkSmith/icons/main/icons/{icon-name}.svg
```

**Example:**
```
https://raw.githubusercontent.com/TheNetworkSmith/icons/main/icons/dashboard.svg
```

### Using in Cloudflare Access

When configuring a Cloudflare Access application:

1. Navigate to your Cloudflare Access dashboard
2. Select the application you want to customize
3. In the application settings, find the "App Launcher" or icon configuration
4. Paste the raw GitHub URL for your chosen icon

### Using in HTML

```html
<img src="https://raw.githubusercontent.com/TheNetworkSmith/icons/main/icons/dashboard.svg" alt="Dashboard" width="24" height="24">
```

### Using as CSS Background

```css
.icon {
  background-image: url('https://raw.githubusercontent.com/TheNetworkSmith/icons/main/icons/shield.svg');
  background-size: contain;
  background-repeat: no-repeat;
}
```

## 📝 Icon Specifications

- **Format:** SVG (Scalable Vector Graphics)
- **Stroke Width:** 2px
- **ViewBox:** 24x24
- **Style:** Outline/stroke-based icons
- **Color:** Uses `currentColor` for easy theming

## 🤝 Contributing

Feel free to contribute additional icons! Please ensure they:

- Are in SVG format
- Use a 24x24 viewBox
- Use stroke-based design (not filled)
- Are simple and clear
- Have descriptive, lowercase filenames
